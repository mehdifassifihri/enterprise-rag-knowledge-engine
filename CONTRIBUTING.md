# Contributing

Use Python 3.12+ and `make setup`. Preserve typed service boundaries and SQL tenant predicates. Run `make lint`, `make test`, dataset validation and PostgreSQL integration checks for persistence/retrieval changes. Use only synthetic fixtures and mocked external calls in automated tests; real paid experiments require explicit authorization. Never add keys, customer data or raw private logs to issues or patches. Document evidence and remaining verification gaps. Licensing is pending; contact the repository owner before contributing code for redistribution.
